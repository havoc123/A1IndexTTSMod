# ASR 启动、常驻、发送与整段复核验证

日期：2026-10-09。源码版本继续为 0.7.6。按用户要求仅进行离线验证，未启动本游戏。

启用 ASR 后，在插件启动时按保存的模型档位异步加载并预热，成功后显示“就绪”，无需先点击麦克风。空闲、切后台、关闭对话和切换 NPC 都保留识别器；只有禁用 ASR、切换模型或插件退出才释放。预热不打开麦克风，空闲不持续推理。窗口失焦会取消当前采集并保留草稿，模型继续常驻。

录音时点击发送，停止采集、等待完整终稿，再调用原生发送一次。点击麦克风停止或达到 60 秒上限只保留草稿。错误、取消、切换输入框、切换 NPC 或手动编辑均撤销待发送操作；原生发送按钮不可用时保留终稿。停止等待期间不提交半成品。

之前“准备中”与“就绪”的问题来自缺少启动预热入口、默认根目录错误，以及 30 秒空闲后主动卸载。发送问题来自录音期间禁用原生发送按钮。此前停止路径只有尾部收尾，没有再次检验完整音频。

## 复核实现与准确性边界

说话期间保持 4 路流式搜索。停止后复用同一个识别器和 CUDA 权重，创建新流，将完整录音以原顺序重放，用 8 路搜索再次解码。原生 v2 通过公开流选项 `a1_final_paths` 调整搜索宽度，每次 Decode 根据当前流重设；下一次普通流仍为 4 路。既有 94 个热词按各模型的词表及预算参与搜索。

复核可能修改句子前部，但更多候选不保证更准确。若复核丢失流式终稿中已完整出现的热词，则保留原来的完整终稿；这只是选择模型输出的两个假设，不进行错字强制替换，也不能证明保留下来的热词符合真实录音。保留原终稿时 Text 与 Tokens 一起恢复。日志报告是否复核、是否改字、选择原因、复核样本数和耗时。

最多保存 61 秒 float32 音频，约 3.72 MiB；覆盖 60 秒录音及采集收尾。超出上限不保存更多音频，继续流式识别。取消会在重放块之间检查会话代际，停止旧复核；旧结果不会发布到新会话。兼容 v1 和官方原生库时只执行原有流式收尾，整段复核要求 v2。

既有 19 条 WAV 包含 18 条 Windows SAPI 合成音和 1 条自然录音，原有分组为 11 条 calibration / 8 条 heldout。指标为每条 CER 的算术平均，不是汇总字符 CER。这些录音不足以代表用户口音或游戏背景声。

| 档位 | 不复核 | 无条件采用 8 路复核 | 加入终稿保留规则 | 改善 / 变差条数 |
| --- | ---: | ---: | ---: | ---: |
| 14M | 10.35% | 10.16% | 10.16% | 1 / 0 |
| 160M | 11.84% | 12.46% | 10.49% | 2 / 1 |

160M 的 heldout 均值由 9.95% 降到 8.39%；14M heldout 仍为 7.62%。自然语音复核补回一个漏掉的末字；160M 改善了“沿着这条路向前走”的前部文字，并保留正确的“苏倾盏”。仍有错字，160M 有一条混合术语录音变差，不能宣称每句复核均改善。

复核耗时受 GPU 争用影响。较早一轮 14M / 160M 复核中位耗时约 0.55 / 1.77 秒；最终选择规则复测时，用户正在运行其他游戏，分别约 2.02 / 4.92 秒，最长约 5.22 / 13.62 秒。等待在 ASR 工作线程进行。原有“停止 p95 ≤ 1 秒”目标尚未达到；这些数据不构成本游戏帧时间验收。

## 常驻资源实测

RTX 5090，独立离线测试进程加载生产识别核心并预热 4 路与 8 路，闲置 15 秒。系统工作集增量以同一进程加载前后相减；显存使用 Windows GPU 计数器按 PID 查询。它包含 CUDA/cuDNN/ONNX Runtime 的初始化成本，不能用权重磁盘大小替代，也不等于本游戏进程的精确增量。

| 档位 | 系统工作集增量 | 私有提交量增量 | 专用显存 | 空闲 GPU 采样 |
| --- | ---: | ---: | ---: | ---: |
| 14M FP32 | 979.5 MiB（约 0.96 GiB） | 1749.0 MiB | 571.6 MiB | 0% |
| 160M FP16 | 1294.3 MiB（约 1.26 GiB） | 2512.8 MiB | 1013.6 MiB | 0% |

两档共享显存计数均为 76 MiB，不能与主存简单相加。私有提交量不等于实际物理内存。15 秒闲置期间，识别核心测试进程新增 CPU 时间分别为 0.015625 秒和 0 秒；该进程没有游戏逻辑，也不包含生产采集控制线程的空闲轮询。预热单次测得约 3.65 / 7.39 秒，其他负载下准确档加载可超过 20 秒。

复测入口：`tools/AsrQualityCheck/Measure-Residency.ps1`，支持 `-Profile` 和 `-RuntimeDirectory`。计数器不可用时输出 null，不能当成零占用。常驻策略按用户要求固定，不再设置前后台卸载计时器。
